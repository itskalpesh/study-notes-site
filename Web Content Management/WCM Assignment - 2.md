1. Explain Presentation Software part 1 and part 2.
- Presentation software is an application used to create, edit, and deliver information through slides containing text, images, charts, audio, video, and animations.
- Examples: Microsoft PowerPoint, Google Slides, Apple Keynote.

- Presentation Software Part 1 covers the basic concepts of creating effective presentations.

    1. Introduction to Presentation Software
    - Presentation software helps create professional slide-based presentations using text, images, charts, and multimedia.
    - Example: Microsoft PowerPoint.

    2. Slide Design and Layout
    - Use simple layouts, readable fonts, proper colors, and relevant images to create attractive slides.
    - Example: Using a consistent theme throughout the presentation.

    3. Content Organization
    - Arrange content in a logical order: Introduction → Main Content → Conclusion.
    - Example: Presenting objectives before explaining the topic.

    4. Adding Multimedia
    - Insert images, videos, charts, and audio to make presentations more interesting and informative.
    - Example: Adding a chart to explain sales data.

     5. Delivery Techniques
     - Present confidently, manage time, maintain eye contact, and practice before presenting.
     - Example: Rehearsing before a seminar.

- Presentation Software Part 2 focuses on advanced features that make presentations more interactive and professional.

    1. Advanced Features
    - Use animations, transitions, and Slide Master to improve the presentation.
    - Example: Applying Fade transition between slides.

    2. Interactivity and Engagement
    - Add hyperlinks, buttons, quizzes, and polls to increase audience participation.
    - Example: Linking a slide to a website.

    3. Collaboration and Sharing
    - Multiple users can edit presentations together and share them online.
    - Example: Team members working on Google Slides.

    4. Accessibility Considerations
    - Use readable fonts, good color contrast, and alt text for images to make presentations accessible to everyone.
    - Example: Adding alternative text to images.

    5. Integration with Other Tools
    - Presentations can be embedded in websites, shared on social media, or exported as PDF and video.
    - Example: Exporting a PowerPoint presentation as a PDF.

2. Explain Screen Casting Tools and Techniques 
- Screen casting is the process of recording or sharing the activities performed on a computer or mobile screen, usually with voice narration, to create tutorials, demonstrations, and training videos.
- Screen Casting Tools

    1. OBS Studio
    - A free and open-source screen recording and live streaming software used for high-quality video recording.
    - Example: Recording online lectures.

    2. Camtasia
    - A professional screen recording and video editing tool with features like annotations, transitions, and animations.
    - Example: Creating educational tutorials.

    3. Snagit
    - A screen capture and recording tool used for taking screenshots and recording short videos.
    - Example: Creating user manuals and software guides.

    4. Loom
    - A cloud-based tool that records the screen, webcam, and microphone and allows instant sharing through a link.
    - Example: Recording project updates.

    5. ScreenFlow
    - A macOS screen recording and video editing software used to create high-quality presentations and tutorials.
    - Example: Producing professional training videos.

- Screen Casting Techniques

    1. Preparation
    - Plan the objective, audience, and required materials before recording.

    2. Scripting
    - Prepare a script or outline for smooth and organized narration.

    3. Screen Recording
    - Record the required screen activities along with audio narration.

    4. Demonstration
    - Clearly explain each step using cursor movements, highlights, or zoom effects.

    5. Editing
    - Remove mistakes and add captions, annotations, transitions, or background music.

    6. Export and Sharing
    - Export the final video in a suitable format (e.g., MP4) and share it through YouTube, email, or LMS platforms.

3. Explain How to Create and Maintain Wiki Sites
- A Wiki site is a collaborative website where users can create, edit, and organize content for knowledge sharing.
- It is commonly used for documentation, knowledge sharing, and team collaboration.
- Creating a Wiki Site
    1. Choose a Platform
    - Select a wiki software such as MediaWiki, DokuWiki, Confluence, or Tiki Wiki based on your needs.
    
    2. Domain and Hosting
    - Purchase a domain name and web hosting to host the wiki on a server.
    
    3. Install Wiki Software
    - Install the selected wiki software using the hosting provider's installer or manual setup.
    
    4. Configure Settings
    - Customize the wiki by setting: User roles and permissions Access controls Theme and appearance Site settings
